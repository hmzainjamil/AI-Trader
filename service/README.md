# Backend service

This directory contains the FastAPI backend source for AI-Trader. Its application entry point is `server/main.py`; route modules, configuration, database access, background tasks, and tests are under `server/`.

The repository is publicly visible, but its root does not contain a license file. This page does not assign a license or establish reuse rights.

For local setup and current project limits, see the [root README](../README.md). The API description files are in [docs/api](../docs/api/). The deployment state and external services were not verified in this documentation update.
